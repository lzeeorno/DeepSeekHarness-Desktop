# Security Policy

Do not report a suspected vulnerability in a public issue. Use a private GitHub security advisory for this repository and include a minimal reproduction, affected commit or release, operating system, and impact.

Never include API keys, private keys, session databases, credentials, or personal filesystem paths in a report. Revoke any credential that was exposed before reporting the issue.

The first public release is a Linux x64 prerelease. macOS and Windows support is still marked Coming Soon, and unsigned CI artifacts are not security endorsements.
