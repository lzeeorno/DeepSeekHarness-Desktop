# Public Research References

`AGENT_SYSTEMS_WHITEPAPER.md` is part of the public project documentation. It links primary papers, official documentation, and licensed upstream repositories by URL and fixed revision.

The downloaded reference repositories under `references/external/` and `references/grok-build-main/`, the unlicensed reverse-engineering material, and the original paper PDFs are local research inputs. They are excluded by `.gitignore` and are not redistributed by this repository.

This separation protects third-party licensing terms and keeps local machine paths, extracted text, and research caches out of the public Git history.
