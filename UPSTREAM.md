# Upstream And Community Distribution

This repository is a community desktop distribution based on [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness). It is not an official DeepSeek release and is not endorsed by DeepSeek.

The source snapshot was based on upstream commit `47f943859bef60e4160492346772ded9b24f765a`. The original MIT license and copyright notice remain in [LICENSE](LICENSE); third-party terms remain in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

The public repository is maintained by [lzeeorno](https://github.com/lzeeorno). The desktop shell, Build/Research workbench, context ledger, release documentation, and public research manifest are community changes. Internal workspace package names retain the upstream scope for source compatibility; this repository does not publish new npm packages under `@deepseek-ai`.

Reference repositories and paper PDFs used during local design research are intentionally excluded from the public tree. Their public source links and fixed revisions are recorded in [the whitepaper](references/AGENT_SYSTEMS_WHITEPAPER.md).
