# Code Of Conduct

Participants in DSH Desktop are expected to communicate with respect, assume good intent, and keep technical discussion focused on improving the project.

Harassment, discrimination, threats, deliberate disruption, and sharing private information are not acceptable. Maintainers may remove content or restrict participation when conduct violates these expectations.

Report conduct concerns privately through the repository's GitHub security contact. Do not include API keys, credentials, private research material, or personal data in a report.
